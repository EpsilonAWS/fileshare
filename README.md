# fileshare

> A zero-trust, temporary digital file transfer system (similar to Firefox Send or SendSafely).

Built with **Full-Stack Next.js (TypeScript + Tailwind + shadcn)** and configured with **adevkit** for modern agentic engineering.

---

## Overview

fileshare is engineered for high performance, modular architecture, and seamless AI agent pair programming.

- **Stack**: Full-Stack Next.js (TypeScript + Tailwind + shadcn) (`nextjs`)
- **Author**: Aayush

```bash

npm run build

# 3. Run typecheck & tests
npm test
```
